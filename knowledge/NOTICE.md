# NOTICE — sources consulted for `measurable_pulses.md`

`measurable_pulses.md` is **original text**, hand-authored for this project. No passage was copied
from any source. What follows records what was consulted and one licence caveat.

## Consulted source
- **Repo:** `jangviktor-web/nihaixia` (Ni Hai-Xia TCM study notes)
- **Branch:** `StableV2026.5.23`  ·  **Commit read:** `ec03c594ed239b570e997cbd396c2fc186b6ad91` (2026-07-14)
- **Files read (rate/rhythm passages only):** `modules/04_jingui.md`, `modules/03_yian.md`
- **What was drawn from it (facts, not text):**
  - 数 (rapid): classically counted against the breath — roughly five beats per one physician
    breath as a baseline; more beats = faster; the source tracks a rising rate over treatment as
    worsening and a falling rate as recovery.
  - 迟 (slow): fewer beats per breath than baseline; framed as a cold/quiet tendency, with noted
    exceptions.
  - 结 (jié): irregular, patternless pauses — "knots on a rope."
  - 代 (dài): regularly intermittent pauses, defined by *counting beats between pauses* (the source
    gives 54-beats-to-a-pause as normal, and a pause every 5 or 10 beats as prognostic milestones).
    This beats-between-pauses ratio is the one classical pulse concept in the repo that beat-level
    (ECG/RR) data could actually compute — **noted for the future ECG milestone; not used in v1**,
    which has no beat-level data.

## Two caveats recorded deliberately
1. **Licence ambiguity.** The repo ships **no `LICENSE` file**. MulanPSL-2.0 is asserted only in
   README prose / a badge pointing at a file that does not exist. Because this project copies **no
   text** and reuses only uncopyrightable ideas expressed in our own words, the ambiguity does not
   affect us — but it is why nothing was transcribed.
2. **促 (cù) is NOT from nihaixia.** An explicit search of both files found no 促脉 / 脉促 content
   (all "促" hits are unrelated words like 短促/促进). Its one-line description here (a rapid rhythm
   carrying occasional irregular pauses) is written from general classical convention
   (濒湖脉学-style: 促 = rapid + irregular pause, vs 结 = irregular pause, vs 代 = regular pause), in
   our own words. Flagged so the provenance is honest.
